Start here

IT Professional

Student or Recent Graduate

Existing Security Professional

03

Choose your path

Choose the cybersecurity path that fits your strengths.

SECURITY OPERATIONS / SOC

Work on:

Security monitoring · Alert triage · Log analysis · Incident investigation · Incident response

Core skills:

Networking · Threat analysis · SIEM · Incident-response fundamentals

Potential roles:

SOC Analyst · Security Operations Analyst · Incident Response Analyst

Evidence: SIEM investigation, log-analysis exercise, alert-triage scenario.

GRC / RISK & COMPLIANCE

Work on:

Risk assessments · Security controls · Compliance · Audits · Policies

Core skills:

Risk management · Security frameworks · Regulatory awareness · Documentation

Potential roles:

GRC Analyst · Risk Analyst · Compliance Analyst

Evidence: Risk assessment, risk register, control mapping, security policy.

CLOUD SECURITY

Work on:

Cloud infrastructure security · IAM · Monitoring · Cloud configuration

Core skills:

Cloud fundamentals · IAM · Network security · Security architecture

Potential roles:

Cloud Security Engineer · Cloud Security Analyst · Security Engineer

Evidence: IAM project, configuration assessment, logging project.

APPLICATION SECURITY

Work on:

Secure coding · Vulnerability assessment · Application and API testing

Core skills:

Software development · Web security · Testing · Vulnerability assessment

Potential roles:

Application Security Engineer · Product Security Engineer · Penetration Tester

Evidence: OWASP assessment, API testing, secure coding project.

Review 10 relevant job descriptions
